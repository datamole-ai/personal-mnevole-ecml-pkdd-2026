# ECML PKDD 2026 — transcripts and summaries

AI-generated transcripts and summaries created by Wispr Flow from recordings of 53 presentations at [ECML PKDD 2026](https://ecmlpkdd.org/2026/), September 7–11, 2026, in Naples, Italy. Shared to make it easier to revisit the talks and find their papers and code.

[Conference](https://ecmlpkdd.org/2026/) · [Proceedings](https://ecmlpkdd.org/2026/proceedings/)

Each presentation folder contains a `README.md` with metadata and verified links, plus Wispr Flow’s `summary.md` and refined `transcript.md`, with personal names redacted. This is an unofficial, partial collection, not the conference proceedings.

The summaries use Wispr Flow’s saved Markdown, and transcripts use its saved refined text segments in their original order. Personal names in both are replaced with `<name>` (shown as inline code so the placeholder remains visible in Markdown). Apart from those redactions, the generated wording is unchanged. Transcripts add blank lines and Markdown speaker headings (`Speaker 1`, `Speaker 2`, etc.) based on Wispr Flow’s assignments within each recording; these labels do not verify anyone’s identity or participation. Automatic summaries and transcripts may contain recognition errors and unresolved speaker tokens. Metadata is checked separately against the program and paper sources.

Paper and repository availability was checked on September 12, 2026. Missing links mean no matching public version was verified, not that none exists. The seal-strength workshop recording has a descriptive title and an explicitly unverified paper identity.

## Sources

Conference metadata comes from the official Whova program, the QCDS workshop program, and the SOMI workshop page. Individual READMEs link to papers and author repositories where verified. Original research belongs to its respective authors; these notes are not author-approved transcripts.
